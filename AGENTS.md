# Repo Notes

- Keep `dev-log/YYYY-MM-DD.md` updated with important events.
- Write brief bullets only: user requests, benchmark numbers, infra state, commands that changed state, gotchas, and agent misunderstandings/wrong turns.
- Record misunderstandings as learning signals. Keep them concrete: what was wrong, what the user corrected, and the resulting rule.
- For benchmarks, include command, topology, TPS target, chain/subnet IDs when relevant, and raw latency numbers.
- Do not add narrative, speculation, or long plans to dev-log files.
