# Example inventories

Copy one to the repository root as `nodes.ini` and replace the hosts. The
annotated reference for every field is `nodes.ini.example`; the oracle-L1
roles it shows belong to the settlement-feed app's multi-chain shape.

- `dev-single-host.ini`: smallest legal fleet on one machine.
- `uat-two-dc.ini`: the two-site failover shape the drills are written for.
